FAQ

Everything you need to know

Which chains does DegenKit support?+
Solana is live today. Robinhood Chain support is next on our roadmap — the same one-signature flow will carry over.
Do I need to code anything?+
No. Fill in your token's name, symbol, decimals and supply, connect your wallet, and sign one transaction. No Solidity, no Rust, no deploy scripts.
Where do my tokens go after I create them?+
Straight into the wallet you connected. Phantom, Solflare, Backpack, and MetaMask's Solana wallet are all supported.
What does it cost?+
A 0.3 SOL service fee, plus the standard Solana network fee — both included in the single transaction you sign.
Can the supply change after my token is created?+
No. Mint and freeze authority are revoked automatically, and metadata is locked (immutable) the moment your token is created — nobody can inflate the supply or edit the token afterward.
Where can I get support?+
Email us — see the Support page for the address and what to include so we can help faster.
Which wallets does DegenKit work with?+
Any Solana wallet that supports the Wallet Standard — Phantom, Solflare, Backpack, and MetaMask's Solana wallet all connect directly, no extra setup.
What's the difference between Airdrop and Multisender?+
Airdrop sends the same fixed amount to every address on your list. Multisender lets you set a different, custom amount for each recipient.
Has DegenKit been audited?+
Not yet by a third-party firm. The code is built on well-established Solana programs (SPL Token, Token-2022, Metaplex), but we'd still recommend testing with a small amount before larger transactions.
